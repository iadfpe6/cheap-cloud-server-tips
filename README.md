### 38元一年的云服务器是真的吗？

真的，但有两个前提：它是秒杀价需要抢，而且要有新用户资格。抢不到就按68元日常价买，同一台机器。

### 新用户特惠在哪里领？

### 便宜云服务器能跑什么？

小型博客、静态站、开发测试环境、轻量API都没问题。高并发Web应用或大型数据库，这个预算的机器都吃力，换哪家也一样。

### 大陆节点一定要备案吗？

用中国大陆地域对外提供网站服务需要ICP备案；不想备案就把服务放在香港或境外节点，代价是国内访问速度打折。

### 按小时计费和按月计费哪个好？

短期项目、用完即删的测试环境选按小时；业务周期明确、要长期在线的，按月或按年更划算。
